# 📊 Stock Market Dashboard

A real-time stock trend analyzer built using Python and Streamlit.

## 🚀 Features

- 📈 Candlestick chart
- 📊 Moving Averages (MA50, MA200)
- 📉 RSI Indicator
- 🧠 Market Insights
- 🚨 Buy/Sell Signals
- ⚡ Live Data (Yahoo Finance)

## 🧠 Tech Stack

- Python
- Pandas
- yFinance API
- Plotly
- Streamlit

## ▶️ Run the App

```bash
pip install -r requirements.txt
python -m streamlit run app.py
